## 最新实现详情：回复风格随机化

### 实现内容

**1. `anti_cliche.rs` — 风格选择 + Prompt 指令**

```rust
// ReplyStyle 枚举
pub enum ReplyStyle {
    Short,   // 短回复 (40%)
    Normal,  // 中回复 (35%)
    Long,    // 长回复 (20%)
    Full,    // 全量 (5%)
}

// 基于对话轮数伪随机选择（Knuth 乘法哈希）
pub fn select_reply_style(dialogue_turn_count: u32) -> ReplyStyle

// 生成 prompt 指令片段
pub fn build_reply_style_hint(style: ReplyStyle) -> &'static str
```

- Short 风格在 prompt 中注入"控制在1-2句话"指令
- Long 风格注入"适当展开"指令
- Normal/Full 不注入额外指令

**2. `chat.rs` — Prompt 注入**

```rust
let reply_style = anti_cliche::select_reply_style(dialogue_turn_count);
let reply_style_hint = anti_cliche::build_reply_style_hint(reply_style);
// 注入到 system prompt 模板中
```

**3. `post_process.rs` — 后处理管道增强**

```rust
fn length_randomize(text: &str, dialogue_turn_count: u32) -> (String, bool)
```

- **Short**: 只保留前 1-2 句，超过 50 字符截断到 35 字符自然断点
- **Normal**: 仅截断 >80 字符的超长句
- **Long**: 仅截断 >120 字符的极长句
- **Full**: 不修改

### 数据流

```
用户消息 → build_cognitive_prompt()
  ├── select_reply_style(turn_count) → ReplyStyle
  ├── build_reply_style_hint() → prompt 指令
  └── 注入 system prompt

模型回复 → run_post_pipeline()
  ├── clean_markers
  ├── censor_blocked + detect_cliche
  ├── emotion_consistency
  ├── inject_imperfections
  ├── length_randomize(turn_count) → 后处理截断
  ├── inject_typo
  ├── smart_segment
  ├── tone_polish
  ├── speech_rhythm
  └── final_clean
```
