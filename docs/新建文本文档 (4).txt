一、先明确：你要的是什么
"AI 记忆神经网络 3D 可视化"有两种主流形态，先确认你要哪种：

形态 A：对话图谱可视化（推荐，可落地）
节点：每条用户消息 / AI 回复 / 记忆条目
边：消息之间的关联（回复关系、记忆引用、情绪关联、时间关联）
3D 师效：节点在 3D 空间中分布，边连接节点，可旋转/缩放/点击

数据来源：你现有的对话历史 + 记忆库 + 情绪/好感度数据
特点：真实数据驱动，有意义，可交互

形态 B：纯视觉装饰（好看但无意义）
节点：随机生成的粒子
边：距离判定连接
3D 效果：粒子流动、脉冲

特点：纯视觉，跟实际记忆无关

我强烈推荐形态 A。因为你的项目有真实的对话数据、记忆数据、情绪数据，做出来的图谱有实际意义，用户能看到"我和 AI 的记忆是如何连接的"，这是独特的体验。纯装饰的粒子效果任何项目都能做，没有差异化。

// memoryGraphBuilder.ts
import { useChatStore } from '../store/chatStore';
import { useMemoryStore } from '../store/memoryStore';
import { useCharacterMindStore } from '../store/characterMindStore';

export function buildMemoryGraph(characterId: string): MemoryGraph {
  const nodes: GraphNode[] = [];
  const links: GraphEdge[] = [];
  
  // 1. 从对话历史生成 user/ai 节点
  const messages = useChatStore.getState().messages[characterId] || [];
  const conversations = groupMessagesByConversation(messages);
  
  conversations.forEach((conv, convIdx) => {
    conv.forEach((msg, msgIdx) => {
      const nodeId = msg.id;
      const nodeType = msg.sender === 'user' ? 'user' : 'ai';
      
      nodes.push({
        id: nodeId,
        type: nodeType,
        label: truncate(msg.content, 20),
        fullContent: msg.content,
        timestamp: msg.timestamp.getTime(),
        nodeSize: nodeType === 'user' ? 6 : 8,
        color: nodeType === 'user' ? '#5B9DAD' : '#FF6A3B',
        emotion: msg.emotion,
        intensity: msg.emotionIntensity,
        affinity: msg.affinityAtTime,
      });
      
      // 回复关系边
      if (msgIdx > 0) {
        const prevMsg = conv[msgIdx - 1];
        links.push({
          source: prevMsg.id,
          target: nodeId,
          type: 'reply',
          weight: 1,
        });
      }
      
      // 时间关联边（跨对话）
      if (convIdx > 0 && msgIdx === 0) {
        const prevConvLastMsg = conversations[convIdx - 1].slice(-1)[0];
        if (prevConvLastMsg) {
          links.push({
            source: prevConvLastMsg.id,
            target: nodeId,
            type: 'temporal',
            weight: 0.3,
          });
        }
      }
    });
  });
  
  // 2. 从记忆库生成 memory 节点
  const memories = useMemoryStore.getState().entries[characterId] || [];
  memories.forEach(mem => {
    nodes.push({
      id: mem.id,
      type: 'memory',
      label: truncate(mem.content, 20),
      fullContent: mem.content,
      timestamp: mem.createdAt instanceof Date ? mem.createdAt.getTime() : Date.now(),
      nodeSize: 4 + (mem.importance || 1) * 2,
      color: '#FFB347',  // 记忆用橙色
      importance: mem.importance,
    });
  });
  
  // 3. 生成情绪节点（每个对话的主导情绪）
  conversations.forEach(conv => {
    const dominantEmotion = getDominantEmotion(conv);
    if (dominantEmotion) {
      const emotionNodeId = `emotion_${conv[0].id}`;
      nodes.push({
        id: emotionNodeId,
        type: 'emotion',
        label: emotionEmoji(dominantEmotion.type),
        timestamp: conv[0].timestamp.getTime(),
        nodeSize: 5 + dominantEmotion.intensity / 20,
        color: emotionColor(dominantEmotion.type),
        emotion: dominantEmotion.type,
        intensity: dominantEmotion.intensity,
      });
      
      // 情绪关联边（连接到该对话的所有消息）
      conv.forEach(msg => {
        links.push({
          source: msg.id,
          target: emotionNodeId,
          type: 'emotion_link',
          weight: 0.5,
        });
      });
    }
  });
  
  // 4. 生成摘要节点
  const summary = memories.find(m => m.category === 'summary');
  if (summary) {
    nodes.push({
      id: 'summary_node',
      type: 'summary',
      label: '对话摘要',
      fullContent: summary.content,
      timestamp: summary.createdAt instanceof Date ? summary.createdAt.getTime() : Date.now(),
      nodeSiz: 12,
      color: '#9B59B6',
    });
    // 摘要引用边（连接到最近 N 条消息）
    const recentMsgIds = messages.slice(-20).map(m => m.id);
    recentMsgIds.forEach(id => {
      links.push({
        source: 'summary_node',
        target: id,
        type: 'summary_ref',
        weight: 0.2,
      });
    });
  }
  
  return { nodes, links };
}

4.2 语义关联边（可选，进阶）
用 embedding 计算消息之间的语义相似度，相似的消息用边连接：


// semanticLinkBuilder.ts
import { getEmbedding } from '../services/aiService';

export async function buildSemanticLinks(messages: Message[]): Promise<GraphEdge[]> {
  const links: GraphEdge[] = [];
  
  // 1. 对所有消息生成 embedding
  const embeddings = await Promise.all(
    messages.map(async msg => ({
      id: msg.id,
      embedding: await getEmbedding(msg.content),
    }))
  );
  
  // 2. 计算两两相似度
  for (let i = 0; i < embeddings.length; i++) {
    for (let j = i + 1; j < embeddings.length; j++) {
      const sim = cosineSimilarity(embeddings[i].embedding, embeddings[j].embedding);
      if (sim > 0.75) {  // 相似度阈值
        links.push({
          source: embeddings[i].id,
          target: embeddings[j].id,
          type: 'semantic',
          weight: sim,
        });
      }
    }
  }
  
  return links;
}

function cosineSimilarity(a: number[], b: number[]): number {
  let dot = 0, normA = 0, normB = 0;
  for (let i = 0; i < a.length; i++) {
    dot += a[i] * b[i];
    normA += a[i] * b[i];
    normA += a[i] * b[i];
    normB += b[i] * b[i];
  }
  return dot / (Math.sqrt(normA) * Math.sqrt(normB));
}
注意：语义关联边计算量大（O(n²)），建议：

只对最近 100 条消息计算
在后台异步计算，不阻塞 UI
相似度阈值设为 0.75（太高没边，太低全是边）

// incrementalUpdate.ts
export class MemoryGraphManager {
  private graph: any;
  private nodeMap: Map<string, GraphNode> = new Map();
  private currentData: { nodes: GraphNode[], links: GraphEdge[] } = { nodes: [], links: [] };
  
  constructor(container: HTMLElement) {
    this.graph = ForceGraph3D()(container);
  }
  
  // 增量添加新消息
  addMessage(msg: Message, prevMsgId?: string) {
    const node: GraphNode = {
      id: msg.id,
      type: msg.sender === 'user' ? 'user' : 'ai',
      label: truncate(msg.content, 20),
      fullContent: msg.content,
      timestamp: msg.timestamp.getTime(),
      nodeSize: msg.sender === 'user' ? 6 : 8,
      color: msg.sender === 'user' ? '#5B9DAD' : '#FF6A3B',
    };
    
    this.currentData.nodes.push(node);
    this.nodeMap.set(node.id, node);
    
    // 回复关系边
    if (prevMsgId) {
      this.currentData.links.push({
        source: prevMsgId,
        target: msg.id,
        type: 'reply',
        weight: 1,
      });
    }
    
    // 增量更新图谱（不重新渲染整个图）
    this.graph.graphData(this.currentData);
  }
  
  // 增量添加新记忆
  addMemory(mem: MemoryEntry) {
    const node: GraphNode = {
      id: mem.id,
      type: 'memory',
      label: truncate(mem.content, 20),
      fullContent: mem.content,
      timestamp: mem.createdAt instanceof Date ? mem.createdAt.getTime() : Date.now(),
      nodeSize: 4 + (mem.importance || 1)  * 2,
      color: '#FFB347',
      importance: mem.importance,
    };
    
    this.currentData.nodes.push(node);
    this.graph.graphData(this.currentData);
  }
  
  // 完全重建（用户切换角色时）
  rebuild(characterId: string) {
    const data = buildMemoryGraph(characterId);
    this.currentData = data;
    this.nodeMap = new Map(data.nodes.map(n => [n.id, n]));
    this.graph.graphData(data);
  }
}

Graph.onNodeHover(node => {
  if (node) {
    // 高亮该节点及其相邻节点
    const neighborIds = new Set();
    currentData.links.forEach(link => {
      if (link.source === node.id) neighborIds.add(link.target);
      if (link.target === node.id) neighborIds.add(link.source);
    });
    
    Graph.nodeColor(n => 
      n.id === node.id || neighborIds.has(n.id) 
        ? n.color 
        : 'rgba(255,255,255,0.1)'  // 非相邻节点变暗
    );
    Graph.linkColor(l =>
      l.source === node.id || l.target === node.id
        ? 'rgba(255,255,255,0.8)'
        : 'rgba(255,255,255,0.05)'
    );
  } else {
    // 恢复
    Graph.nodeColor(n => n.color);
    Graph.linkColor(l => l.color);
  }
});

Graph.onNodeClick(node => {

  const distance = 40;
  const distRatio = 1 + distance / Math.hypot(node.x, node.y, node.z);

九、性能优化清单
节点数	策略	预期帧率
< 100	默认配置	60fps
100-500	关闭节点拖拽	30-60fps
500-1000	用 sprite 节点 + 关闭拖拽	30fps
1000-5000	sprite 节点 + 关闭拖拽 + 减小斥力	20-30fps
> 5000	分页加载（只显示最近 N 条）+ sprite 节点	30fps
关键优化：

sprite 节点：节点数 > 500 时，用 SpriteText 代替 mesh，性能提升 5-10 倍
关闭拖拽：enableNodeDrag(false)，节点拖拽会触发物理重算
分页加载：节点数 > 5000 时，只显示最近 1000 条，旧的折叠
增量更新：新消息增量添加，不重建整个图
Web Worker：embedding 计算放到 Web Worker，不阻塞 UI
WebGL 渲染：3DForceGraph 底层用 WebGL，已经比 Canvas 快很多

十二、核心总结
技术选型：3DForceGraph（基于 Three.js + d3-force），专为 3D 力导向图设计，API 简单，性能好。

数据来源：你现有的对话历史 + 记忆库 + 情绪/好感度数据，转换成图谱数据结构。

节点设计：

user 节点（蓝色）：用户消息
ai 节点（橙色）：AI 回复
memory 节点（橙黄）：记忆条目
emotion 节点（情绪色）：对话主导情绪
summary 节点（紫色）：对话摘要
边设计：

reply 边：回复关系（最核心）
memory_ref 边：记忆引用
emotion_link 边：情绪关联
temporal 边：时间关联
semantic 边：语义关联（进阶）
summary_ref 边：摘要引用
核心交互：

旋转/缩放/拖拽
悬停高亮邻居
点击查看详情
过滤器按类型过滤
时间轴动画
性能优化：节点数 > 500 时用 sprite 节点 + 关闭拖拽 + 分页加载。

一句话总结：用 3DForceGraph 把你的对话历史 + 记忆库 + 情绪数据可视化成 3D 力导向图，节点是消息/记忆/情绪，边是回复/引用/关联关系，用户能看到"我和 AI 的记忆是如何连接生长的"。你的项目已经有完整的数据层，只差可视化这一步。
